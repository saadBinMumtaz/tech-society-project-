🎓 Uni Tech Society Website

A lightweight, responsive, and modern website for our University Tech Society, built using standard web technologies (HTML, CSS, and JavaScript). It serves as a digital hub to showcase events, workshops, team members, and register new participants.

🚀 Features

Home Page: Intro to the society, mission statement, and latest updates.

Events Section: Display of upcoming workshops, hackathons, and tech talks.

Team Showcase: Meet the minds behind the society.

Registration Form: An interactive form for students to join or sign up for events.

Dark/Light Mode: Smooth theme toggling (via JS).

Fully Responsive: Optimized for mobile, tablet, and desktop viewports.

🛠️ Built With

HTML5: Semantic markup & structure.

CSS3: Custom styling, grid/flexbox layouts, and smooth animations.

JavaScript (ES6): Interactive components, theme switching, and form validation.

📂 Project Structure

uni-tech-society/

⚙️ Quick Start

No installation or build steps are required!

Clone or Download this repository.

Open index.html in any web browser to view the site.

To edit, open the project folder in a code editor like VS Code.
